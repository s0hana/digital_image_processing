## About This Course  

In this course, I learn the fundamental concepts of Digital Image Processing.  
I focus on implementing different image processing techniques using Python.  

This lab helps me understand:

- Image transformation  
- Image enhancement  
- Image restoration  
- Image filtering design  
- Practical applications of image processing  

---

## Course Contents  

### Lab 1: Introduction to MATLAB and Python  
In this lab, I practice basic image operations and become familiar with image processing tools.

### Lab 2: Image Transformation, Enhancement and Restoration  
I implement various enhancement and restoration techniques.

### Lab 3: Color Image Processing  
I work with color images and apply histogram-based techniques like equalization and matching.

### Lab 4: Morphological Operations  
I implement different filtering and derivative-based operations such as gradient and second derivatives.

### Lab 5: Image Segmentation and Object Recognition  
I apply segmentation techniques to detect and analyze objects in images.

---

### CLO2
